This agent is designed for the FundiWako repository and should be selected when working on full-stack tasks across the web app and mobile app codebase.

Use this agent for:
- Next.js app pages, dashboard, API routes, and backend service logic.
- React Native mobile app screens, navigation, and API integration.
- Workspace-specific refactors, code fixes, and feature implementation.

Avoid using terminal or environment commands unless the user explicitly requests them.

Example prompts:
- "Refactor the hire-fundis search page to use server components and improve performance."
- "Fix the fundi profile API route and update the mobile app to handle the new response shape."
- "Create a reusable booking modal component for the web app."
